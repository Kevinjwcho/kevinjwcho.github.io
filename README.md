# kevinjwcho.github.io

Personal website of Jinwoo (Kevin) Cho. Plain static files, no build step.

- `index.html`, `support.js` — landing page
- `site/index.html` — journal version (projects, publications, CV)
- `site/data.js` — all content (projects, publications, software, CV, news); edit this to update the site

Pushing to `master` publishes to the `gh-pages` branch, which GitHub Pages serves.
The previous al-folio (Jekyll) site is in the history before the `new-site` merge.
